# Python Basic Projects

This repository contains beginner-level Python programs created for practice and learning.

## 📌 Projects Included
- Calculator
- Number Guessing Game
- Password Generator
- To-Do List
- Quiz Game
- Prime Number Checker
- Palindrome Checker
- Contact Book
- Dice Rolling Simulator
- Password Strength Checker

## 🛠️ Technologies Used
- Python 3

## ▶️ How to Run

1. Install Python
2. Clone this repository
3. Run program:

python filename.py

Example:
python calculator.py

## 🎯 Purpose
These projects were created to improve Python programming skills and understand basic programming concepts.
